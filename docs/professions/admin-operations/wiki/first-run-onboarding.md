## What It Is

First-run onboarding turns a fresh install into an operable platform. The administrator validates provider readiness, user access, workspace configuration, seed state, and recovery visibility before the user depends on AI coworker workflows.

## Operating Rule

Make the next action clear. A non-technical operator should not need to infer whether the platform needs a provider, a token, a migration, a seed pass, or a workspace bootstrap.

## How To Apply

1. Confirm the install has a usable runtime and workspace readiness state.
2. Check provider configuration before asking coworkers to act.
3. Verify access roles and admin authority paths.
4. Turn setup blockers into explicit backlog or recovery records.
