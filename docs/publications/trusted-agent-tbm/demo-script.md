1. **0:00–1:00, modeled obligation.** Show the requirement, stage, owning decision, capability envelope and assertion. Explain the platform, business and profession scopes. A model explains intended controls; execution still checks current facts.
2. **1:00–2:00, eligible synthetic expense.** Show required evidence and the exact frozen test policy. After separate specimen approval and qualified runtime admission, allow only the isolated synthetic-record approval. Show the actual effect receipt, never “payment completed.” Until then, use the static specimen below.
3. **2:00–3:00, missing evidence.** Remove one required item. Apply the frozen policy's hold/deny behavior and establish that no approval effect occurred. A plausible explanation cannot supply missing evidence.
4. **3:00–4:00, changed authority/policy.** Revoke test authority or change the binding/policy between recommendation and execution. Observe refusal and no effect; a previous permit is not current authority.
5. **4:00–5:00, replay/recovery.** Replay the same request against its stable effect identity. Verify the declared duplicate behavior and actual effect count. Existing receipts establish past facts, not permission for new effects.
6. **5:00–6:00, material change.** Change one controlled operating-profile component. Show the declared impact/revalidation response. Do not silently inherit qualification.
7. **6:00–7:00, assessment.** Show applicable requirements, passed/failed assertions, unsupported cases and required human assessment. Cost and supervision remain “not measured” without actual measurements.
