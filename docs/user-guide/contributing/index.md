## Who This Section Is For

This section is for people changing the **platform's source code** — not for people running a business on it.

If you own or work in the business this install serves, you do not need anything here. Go to [Getting Started](../getting-started/index.md) instead. Nothing in this section is required to set up your portal, work your daily board, or use your AI coworkers.

If you want to change how the platform behaves without touching source, that is [Build Studio](../build-studio/index.md) — the governed, guided path. It does not require any of the setup below.

## Pages

- [Developer Setup](developer-setup.md) — run the codebase locally with pnpm and Docker sidecars, with IDE integration, debugging, and hot reload.
- [Dev Container Setup](dev-container.md) — the fully containerized alternative; needs only Docker Desktop and VS Code, no local Node.js or pnpm.
- [Agent Development Environments](agent-dev-environments.md) — set up Claude, Codex, and Grok as governed coding agents: MCP, the skill pack, AGENTS.md, local client settings, and running concurrent threads safely.
