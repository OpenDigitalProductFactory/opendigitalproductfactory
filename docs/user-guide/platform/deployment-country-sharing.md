## Use This Doc For

- Deciding whether to tell the organization you buy from where this installation runs
- Knowing exactly what is shared, with whom, and how to stop

## Where To Find It

**Platform → Connections** (`/platform/federation-links`). Look for "Share this installation's country".

## What It Does

When you turn it on, this installation tells the organizations it is connected to "above" it which country it runs in. These are the organizations that manage it, or that supply it through a channel partner. They can then count it on their market map.

- **Only the country is shared.** It comes from your organization's address. No street, city, postcode, map position or IP address is ever sent.
- **It is off until you turn it on.** Nothing is shared by default.
- **Turning it off withdraws it.** The organizations above stop counting this installation.
- **It goes only upward.** It is never sent to installations you manage, to partners at the same level, or to any public directory.

The panel lists the connections that receive it. If it says none do, this installation has no connection to an organization above it.

## If The Switch Is Unavailable

Add a country to your organization's address first. The switch uses the same address the rest of the platform uses, so you never type the country twice.
