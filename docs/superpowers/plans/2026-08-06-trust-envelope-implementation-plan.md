## Design grounding

Source of truth is the spec above (its §"Design grounding" verified the substrate).
This plan extends that spec into code. Blast radius is deliberately minimized: the
five phases land as **new self-contained modules** under `apps/web/lib/decision/`
with small **additive, backward-compatible** wiring into the kernel hot path — the
evidence-enforcement and sealing are opt-in/fail-open so every existing
`principle_decide` caller and test is unaffected (verified: existing
`kernel-consult-ledger` + `principle-decide-pack` suites still green).

## Out of scope (tracked, not silently dropped)

- **B2 signing / B3 external anchoring tiers** — deferred per Fork B (spec §7); operator ratifies tier boundaries (spec §10 Q1) before build.
- **A full ATS/applicant substrate** — none exists (spec §6.4/§10 Q4). Phase E is the decision-trust LAYER a future ATS plugs into, not the ATS.
- **Wiring the jurisdiction resolver + re-verifier into the live pack request path for WSID** — Phase D/C ship as composable libraries + schema now; the candidate-eval surface consumes them in a follow-on once the ATS substrate exists.
