## What this report does not tell you

- **Whether a ratio is right.** Nothing anchors ratios, which is BI-EF97E987. This measures the spread; it cannot judge it.
- **Whether an axis belongs in a vector.** That needs the orthogonality statement proposed in BI-4CF7DCC4.
- **Which principles actually move a decision.** That needs the golden-decisions panel, which scores a curated scenario set rather than the whole space.
