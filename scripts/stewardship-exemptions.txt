# Stewardship retention exemptions (BI-C34E09B0).
#
# The third disposition. A persistent Prisma model normally declares itself
# either purgeable (PURGE_POLICIES) or regulated-retained (RETAINED_DATASETS) in
# apps/web/lib/operate/retention/policies.ts. Some models legitimately belong to
# NEITHER — and before this file, that was expressed only by ABSENCE, which is
# indistinguishable from the silent omission the gate exists to catch.
#
# Format:  ModelName  reason-slug  # rationale
#
# Valid reason slugs (closed set — packages: scripts/lib/stewardship-scope.mjs):
#   reference-data            Reference / lookup data. Superseded by
#                             replacement, never aged out.
#   config-singleton          Single-row (or per-org) configuration. Lifetime is
#                             the install's lifetime.
#   domain-lifecycle-managed  Rows are created and removed by their own domain
#                             lifecycle, so a time-based sweep races that owner.
#   derived-projection        Derived from a source of record; rebuilt or
#                             cascaded, never independently aged.
#
# DO NOT use this file to park a model you have not thought about — that is what
# the ratchet baseline (stewardship-scope-baseline.txt) is for. An entry here is
# a positive assertion that no retention window applies.
#
# Equally: do NOT resolve a gap by inventing a purge window. The retention engine
# EXECUTES PURGE_POLICIES; a fabricated window on reference data deletes it.

# A row's meaningful lifecycle (when it stops being live evidence a human
# should still look at) is owned by an explicit domain action, not by age.

  # would race the still-open review queue and would delete governance
  # evidence a real regulated-retention floor doesn't apply to but the
  # decision ledger it's attached to (DecisionInteraction) does need intact.
